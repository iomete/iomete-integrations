## 0.1.0 (Sep 9, 2026)
- First release of the IOMETE Tableau connector. Connects Tableau Desktop and Server 2024.2+ to IOMETE through the Arrow Flight SQL JDBC driver, on Windows, macOS, and Linux.
- Supports live and extract connections, username and access token authentication, and JDBC over TLS.
- The Arrow Flight SQL JDBC driver is installed separately; see the README for the driver and certificate steps.
